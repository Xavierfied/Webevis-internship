# Video Object Detection (VOD) — YOLOv8 Tracker

Real-time video object detection and tracking using YOLOv8 and OpenCV.

---

## Project Structure

```
video_track_yolo/

│   ├── processed/

│   └── test/

├── main.py
├── README.md
└── requirements.txt
```
